# 前端操作说明书（九厂一期工艺参数监控大屏）

系统对 4 台设备做实时监控，越限/离线自动告警并按名单发短信/微信通知。界面三个页面：实时监控 · 告警记录 · 阈值配置。

## 1. 顶栏（所有页面通用）

| 控件 | 逻辑 |
|---|---|
| 菜单：实时监控 / 告警记录 / 阈值配置 | 点击切换页面 |
| 🔔 铃铛按钮 | 点击 = 全部标记已读 + 跳转告警记录页；红数字 = 未读数（>99 显示 99+，无未读隐藏） |
| 检测器运行中 / 已停止 | 后端检测器心跳，绿=在岗、红=已停，60 秒刷新；无此项 = 前端跑在模拟模式（不连后端） |
| 在线/离线/异常计数 | 四台设备状态统计，实时刷新 |
| 时钟 | 当前时间 |

## 2. 实时监控页

数据约 2 秒自动刷新。

**设备卡片（整张可点）**：显示编号、状态角标、6 项指标值（越限项红色加粗）、最近上报倒计时（超 13 分钟判离线）。点击卡片 → 打开详情抽屉。

**状态角标规则**（仅展示，不参与真正报警）：

| 状态 | 规则 |
|---|---|
| 离线 | 超 13 分钟无上报 |
| 异常 | 任一参与监控指标严格越限（压线不算） |
| 在线 | 其他 |

**详情抽屉**：

| 控件 | 逻辑 |
|---|---|
| × / 点抽屉外 | 关闭 |
| 6 个参数值方块 | 点击切换下方趋势图到该参数；默认选中沉降比 |
| 档案信息 / 照片 / 趋势图 | 展示 |

## 3. 告警记录页

后端检测器生成告警（浏览器关着也产生），本页 30 秒自动刷新；新告警弹通知（严重红/警告黄）+ 铃铛角标 +1。

| 控件 | 逻辑 |
|---|---|
| 「筛选」+「设备」下拉 | 按设备筛选，未选时显示「全部」，点 × 清除 |
| 「筛选」+「类型」下拉 | 按类型筛选（超上限/超下限/离线），未选时显示「全部」，点 × 清除；两下拉可组合 |
| 按钮「清空记录」 | 二次确认后清空全部告警 |

列表列：时间 / 设备（编号）/ 参数（离线显示「整机」）/ 类型 / 当前值（离线 `--`）/ 阈值（离线 `--`）/ 级别（警告/严重）/ 短信（已发送/发送中/失败 + 接收人数，名单空显示失败）。

> 记录最多 500 条，超出自动丢最旧。

## 4. 阈值配置页

### 4.1 告警阈值

| 控件 | 逻辑 |
|---|---|
| 4 个设备标签页 | 切换设备，每页 6 指标 |
| 下限 / 上限输入框 | 改数值，小数位按指标固定 |
| 参与监控开关 | 关 = 该指标越限不报警 |
| 按钮「保存」 | 校验下限<上限：失败红字报具体设备+指标，不保存；成功提示「约 10 秒内采纳」。角标立即生效，后端约 10 秒采纳 |

### 4.2 接收人

| 控件 | 逻辑 |
|---|---|
| 按钮「添加接收人」 | 打开弹窗 |
| 订阅设备勾选框（每行 4 个） | 勾选/取消**立即保存**；全不勾提示「未订阅任何设备」 |
| 「微信 openid」列 | 展示（未配显示灰字「未配置」） |
| 按钮「编辑」 | 打开弹窗并回填 |
| 按钮「删除」 | 二次确认后移除 |

> 某设备无人订阅时，其告警通知记「失败」、接收人为空。

### 4.3 接收人弹窗（添加/编辑共用）

| 控件 | 逻辑 |
|---|---|
| 姓名 | 必填，空则提示「请输入姓名」 |
| 手机号 | 必填，须 1 开头 11 位，否则提示错误 |
| 订阅设备勾选组 | 勾选订阅设备 |
| 微信 openid | 可选，不填则微信发不了（短信照常）；清空保存 = 取消微信渠道；可手填 |
| 二维码 | 手机微信扫码关注测试号 |
| 按钮「获取最新关注」 | 拉最新未绑定关注者 openid |
| 按钮「取消」 | 关闭，丢弃修改 |
| 按钮「确定」 | 校验姓名/手机号后保存 |

**「获取最新关注」分支逻辑**：点按钮（加载中防连点）→ 拉取结果：

| 情况 | 行为 |
|---|---|
| 拉到 openid 且输入框空 | 自动填入 + 绿字「已填入：x 分钟前关注」 |
| 拉到 openid 但输入框已有值 | 不覆盖，提示「已有 openid，未覆盖；换人先清空」 |
| 无人新扫码 | 提示「暂无新关注」 |
| 渠道没配/接口异常 | 提示「获取失败」 |

已绑定过接收人的关注者不会被拉到；填入后核对时间再确定。

## 5. 微信模板消息（八行）

告警触发后，配了 openid 的订阅人收到公众号模板消息，八行固定结构：

```
设备：Di-Jiu-Shui-Chang-1
沉降速度：1.5m/h
沉降比：19.66%
机加池出水浊度：9.5NTU
pH：7.21
温度：18.6°C
反应池污泥浓度：3.2g/L
异常：沉降比 低于下限 25
```

- 六项指标为当前实时快照，离线时无读数行填「-」；
- 「异常」行：`参数名 超上限/低于下限 阈值`；离线为「设备离线 超过13分钟」；
- 设备号 20 字、其余 16 字截断加「…」，深蓝色；短信同样附六项快照。
